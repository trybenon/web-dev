# #25: отпечаток видеофайла по выборке

## Цель

Проверить, может ли клиент быстро сравнивать выбранные локальные видеофайлы,
не читая многогигабайтный файл целиком. Прототип находится в
`spikes/file-fingerprint/`; инструкция по запуску — в его README.

## Алгоритм прототипа

Версия 1: `sizeBytes`, `durationMs` (округлённая браузером длительность),
`sampleBytes = 1048576` и SHA-256 трёх фрагментов: начала, середины и конца.
Точные смещения записаны в `spikes/file-fingerprint/README.md`. Имя файла
в отпечаток не входит. Читается до 3 МиБ независимо от размера фильма.
Измеряются отдельно время получения метаданных, время чтения и хеширования,
а также общее время.


## Браузерные замеры в Chrome на Mac 

Один и тот же файл `Алдар Батуев 18.10.25.mp4`, размер 552 606 873 байта
(примерно 527 МиБ), длительность 3 136 867 мс. 

| Запуск | Метаданные, мс | Чтение и SHA-256, мс | Всего, мс | Прочитано, байт |
|---|---:|---:|---:|---:|
| 1 | 23 | 8 | 31 | 3 145 728 |
| 2 | 37 | 6 | 42 | 3 145 728 |

JSON-отпечатки двух запусков совпали полностью: размер, длительность и три
SHA-256 одинаковы. Этот файл меньше нескольких гигабайт, поэтому отдельно
проверен большой файл.

## Вывод: берём

Выборочный отпечаток подходит для **быстрой предварительной сверки** локальных
видеофайлов: на проверенном файле 4,18 ГиБ прототип явно прочитал только
3 МиБ для SHA-256 и завершил расчёт за 14–30 мс в Chrome и 180–299 мс
в Safari. Результаты повторились и совпали между браузерами для этого файла.
Сверка разных файлов также дала разные отпечатки. Для интеграции в продукт
стоит согласовать точную схему JSON и правило обработки длительности между
браузерами.

Ограничения: 
- изменения за пределами выбранных участков не обнаруживаются
- продолжительность некоторых форматов браузер не может прочитать
- разные браузеры могут округлять длительность по-разному. Следовательно, этот
отпечаток не заменяет полный хеш или криптографическую проверку равенства.
Если расхождения длительности окажутся частыми, потребуется нормализация
или исключение длительности из строгого сравнения.
