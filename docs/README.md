# Документация

Проектная документация сервиса совместного просмотра видео.

## С чего начать

Если вы здесь впервые — читайте `architecture.md`. Он объясняет, что за
приложение, из чего состоит и почему основная сложность на клиенте.

## Что где лежит

| Файл | О чём |
|---|---|
| `architecture.md` | Из чего состоит система: границы, модули клиента, источник видео |
| `protocol.md` | Какими сообщениями обмениваются клиент и сервер |
| `sync-start.md` | Сценарий: одновременный старт воспроизведения |
| `sync-latejoin.md` | Сценарий: подключение к идущему просмотру |

Первые два описывают статику — что существует и кто с кем связан.
Остальные описывают динамику: что происходит по шагам в конкретной ситуации.

## Диаграммы

Все диаграммы написаны на Mermaid прямо внутри markdown-файлов.
GitHub рендерит их при просмотре, ничего устанавливать не нужно.
Для правки удобен [Mermaid Live Editor](https://mermaid.live).

## Как поддерживать

Документы ссылаются друг на друга, и решения в них связаны. Если меняете
что-то в протоколе или в сценарии — проверьте, не устарело ли описание
в соседних файлах.

В конце каждого сценария есть раздел с открытыми вопросами. Это не забытые
места, а решения, отложенные осознанно. Когда вопрос закрывается — переносите
ответ в основной текст.
