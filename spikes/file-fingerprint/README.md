# Прототип отпечатка файла (#25)

В корне репозитория запустите `python3 -m http.server 8000`, откройте
`http://localhost:8000/spikes/file-fingerprint/` в Chrome или Safari и выберите
видеофайл. Python здесь только отдаёт статические файлы, сам расчёт происходит
локально в браузере и видео не загружается на сервер.

Алгоритм: записываем в JSON размер в байтах, длительность из `loadedmetadata` (округление до
миллисекунд), SHA-256 трёх фрагментов по 1 МиБ: начало `[0, n)`, середина
`[floor((size-n)/2), floor((size-n)/2)+n)`, конец `[size-n, size)`, где
`n = min(size, 1 МиБ)`. Для маленьких файлов фрагменты перекрываются.
Сравнивать нужно все поля JSON, кроме имени файла и времени расчёта.

Выборочный отпечаток помогает находить несовпадающие файлы, но не гарантирует
побайтовое совпадение: изменения вне трёх фрагментов он не увидит.
